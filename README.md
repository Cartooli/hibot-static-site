# hibot-static-site

> A minimal link-in-bio landing page. Perfect for learning HTML, CSS, and JavaScript with zero build steps.

Built with **HTML, CSS & JavaScript**.

## Quick Start

1. Clone: `git clone https://github.com/Cartooli/hibot-static-site.git`
2. Open: `index.html` in your browser
3. Edit: Customize the links, colors, and content
4. Deploy: Push to GitHub Pages or Vercel

## What You'll Learn

- Core concepts of HTML, CSS & JavaScript
- How hibot-static-site is structured
- How to customize and deploy your own version

## See It Live

Open the demo and see it in action, then rebuild it your way on [code.hibot.space](https://code.hibot.space/edtech-tutorials.html).
